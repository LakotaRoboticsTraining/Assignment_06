# Module 1 Review: Lessons 1-5

## Lesson 1: Intro and Setup

This lesson establishes the fundamental structure required for every Java program. Students learn how to define a class-the basic blueprint of Java code-and implement the main method, which serves as the mandatory starting point for program execution. Understanding this boilerplate setup is essential before moving into logic and data storage.

## Lesson 2: Variables and Primitive Types

In this lesson, students learn how to store and manipulate data using variables and primitive types. Key concepts include:

- Data Types: The use of int for whole numbers, double for decimals, boolean for true/false values, and char for single characters.
- Operators: Using the assignment operator (=) to store values, the addition operator (+) for arithmetic, and comparison operators (> and <) to produce boolean results.
- Concatenation: Joining text and variables together using the + symbol to create descriptive output for the console.
## Lesson 3: Methods

Students explore how to organize their code into reusable, named blocks called methods.

- Structure: The difference between parameters (the variables defined in a method's recipe) and arguments (the actual values passed when calling the method).
- Return Types: Distinguishing between void methods, which perform an action but return nothing, and methods that calculate and return a specific value to the caller.
- Overloading: The ability to define multiple methods with the same name as long as their parameter types differ, allowing for flexible code design.
## Lesson 4: Conditionals

This lesson introduces decision-making capabilities, allowing programs to choose different paths based on data.

- Branching Logic: Implementing if, else if, and else statements to execute specific blocks of code only when certain criteria are met.
- Boolean Logic: Combining comparisons and logical operators (like && and ||) to evaluate complex true or false conditions.
|---|
## Lesson 5: Loops

The final lesson of this review focuses on repetition, enabling the program to run code multiple times efficiently.

- Iteration: Using for or while loops to repeat tasks, such as running a robot's motor for several steps or counting down values.
- Integration: Applying the conditions and comparison logic from Lesson 4 to control how long a loop runs, ensuring the code repeats until a specific goal is achieved.
